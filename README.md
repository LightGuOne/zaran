# 雜然

## 简介
自然码双拼 + 魔然字词/拆字 + 万象模型

## 说明
本方案仅是本人根据“一次输入即得正确结果”的需求，在魔然方案基础上修改而成。

### 主要输入方式
- 字词挂接
- 句中辅整句

### 核心 Lua 模块
- `pseudo_moran.lua`
- `moran_reorder_filter.lua`
- `moran_pin.lua`

可以移除`zaran.custom.yaml`抛弃辅助功能。

## 词库与翻译器设计
为利用万象词库（整句准确率高），本方案使用两个翻译器：
- **固词翻译器**：基于不含自造词的纯净词库
- **frequency 翻译器**：支持词频动态调整

以上两个翻译器与原字词翻译器 `fixed` 一同由 `pseudo_moran.lua` 处理，以提高候选词首次命中的概率。  
字词部分与魔然方案基本保持一致。  

> 本方案内kagiroi是缩减版，只保留基础功能  

> 魔然官网：https://www.zrmfans.cn/zh-Hans/book/  
## 快符（后置触发）
快符引导键为 `/`，后置输入：

| 输出 | 输入码 | 说明 |
|------|--------|------|
| `'`  | `a/`   | 左单引号 |
| `·`  | `j/`   | 间隔号 |
| `_`  | `x/`   | 下划线 |
| `……` | `s/`   | 省略号 |
| `.`  | `d/`   | 点号 |
| `——` | `h/`   | 破折号 |
| `“`  | `q/`   | 左双引号 |
| `”`  | `w/`   | 右双引号 |
| `『` | `u/`   | 左直角引号 |
| `』` | `i/`   | 右直角引号 |
